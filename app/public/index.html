Vertex AI Proxy API Reference

Server is running

Overview

A passthrough proxy for accessing Claude and Gemini models on Vertex AI. Provides permanent user secret authentication instead of complex short-lived GCP access tokens.

Supported Providers

Provider Model Prefix Example Models Streaming Method
Claude claude claude-opus-4-5@20251101, claude-sonnet-4-5@20250929 :streamRawPredict
Gemini gemini gemini-2.0-flash, gemini-1.5-pro, gemini-3-pro-preview :streamGenerateContent

API Endpoint

POST /v1/projects/{project}/locations/{location}/publishers/{publisher}/models/{model}

Path Parameters

Parameter Description Example
project GCP project ID (can be overridden by server config) my-gcp-project
location Vertex AI region global, us-central1
publisher Model publisher anthropic, google
model Model name with optional method suffix gemini-2.0-flash:streamGenerateContent

Authentication

Include your user secret in the Authorization header:

Authorization: Bearer your-secret-token

Claude Provider API

Uses the Anthropic Messages API format.

Request Body

Field Type Required Description
messages array Yes Array of message objects with role and content
max_tokens integer No Maximum tokens to generate (default: 8192)
system string No System prompt
temperature number No Sampling temperature (0-1)
tools array No Tool definitions for function calling
tool_choice object No Tool selection configuration
thinking object No Extended thinking configuration

Example Request

POST /v1/projects/my-project/locations/global/publishers/anthropic/models/claude-sonnet-4-5@20250929:streamRawPredict
Authorization: Bearer your-secret-token
Content-Type: application/json

{
  "messages": [
    {"role": "user", "content": "Hello, how are you?"}
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}

Response Format (Streaming)

SSE format with event types: message_start, content_block_delta, message_delta, message_stop

Gemini Provider API

Uses the Vertex AI GenerateContent format with support for function calling.

Request Body

Field Type Required Description
contents array Yes Array of content objects with role and parts
generationConfig object No Generation parameters (temperature, maxOutputTokens, etc.)
tools array No Function declarations for function calling
toolConfig object No Function calling configuration (mode: AUTO, ANY, NONE)
systemInstruction object No System instruction content

Generation Config

Field Type Default Description
maxOutputTokens integer 8192 Maximum tokens to generate
temperature number 1 Sampling temperature
topP number 0.95 Top-p sampling
thinkingConfig object - Extended thinking configuration

Example Request (Basic)

POST /v1/projects/my-project/locations/global/publishers/google/models/gemini-2.0-flash:streamGenerateContent
Authorization: Bearer your-secret-token
Content-Type: application/json

{
  "contents": [
    {"role": "user", "parts": [{"text": "What is 2+2?"}]}
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 1024
  }
}

Example Request (Function Calling)

POST /v1/projects/my-project/locations/global/publishers/google/models/gemini-2.0-flash:streamGenerateContent
Authorization: Bearer your-secret-token
Content-Type: application/json

{
  "contents": [
    {"role": "user", "parts": [{"text": "What's the weather in Tokyo?"}]}
  ],
  "tools": [{
    "functionDeclarations": [{
      "name": "get_weather",
      "description": "Get current weather for a location",
      "parameters": {
        "type": "object",
        "properties": {
          "location": {
            "type": "string",
            "description": "City name"
          }
        },
        "required": ["location"]
      }
    }]
  }],
  "toolConfig": {
    "functionCallingConfig": {
      "mode": "AUTO"
    }
  }
}
Note: The proxy automatically converts parameters to parametersJsonSchema format required by the GenAI SDK. Standard JSON Schema types (lowercase) are supported.

Response Format (Streaming)

SSE format with data: prefix. Each chunk contains candidates with content parts.

data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"}}]}

Function Call Response

data: {"candidates":[{"content":{"parts":[{"functionCall":{"name":"get_weather","args":{"location":"Tokyo"}}}]}}]}

OpenAI-Compatible API

An alternative endpoint that accepts OpenAI chat completion format. Requests are automatically translated to Claude or Gemini format based on the model name.

Endpoint

POST /v1/chat/completions

Request Body

Field Type Required Description
model string Yes Model name (e.g., claude-3-5-sonnet, gemini-1.5-pro)
messages array Yes Array of messages with role and content
stream boolean No Enable streaming (default: false)
max_tokens integer No Maximum tokens to generate (default: 8192)
temperature number No Sampling temperature (0-2)
tools array No Tool/function definitions
tool_choice string|object No "auto", "none", "required", or specific function

Example: Basic Request

POST /v1/chat/completions
Authorization: Bearer your-secret-token
Content-Type: application/json

{
  "model": "claude-3-5-sonnet",
  "messages": [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Hello, how are you?"}
  ],
  "max_tokens": 1024,
  "stream": true
}

Example: Tool Calling

POST /v1/chat/completions
Authorization: Bearer your-secret-token
Content-Type: application/json

{
  "model": "claude-3-5-sonnet",
  "messages": [
    {"role": "user", "content": "What's the weather like in Tokyo?"}
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get the current weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": {
              "type": "string",
              "description": "City name, e.g., Tokyo, London"
            },
            "unit": {
              "type": "string",
              "enum": ["celsius", "fahrenheit"],
              "description": "Temperature unit"
            }
          },
          "required": ["location"]
        }
      }
    }
  ],
  "tool_choice": "auto"
}

Tool Call Response

{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "created": 1699000000,
  "model": "claude-3-5-sonnet",
  "choices": [{

Authorization: Bearer your-secret-token

Streaming Response Format

SSE format compatible with OpenAI SDK:

data: {"id":"chatcmpl-xxx","object":"chat.completion.chunk","created":1699000000,"model":"claude-3-5-sonnet","choices":[{"index":0,"delta":{"role":"assistant"},"finish_reason":null}]}

data: {"id":"chatcmpl-xxx","object":"chat.completion.chunk","created":1699000000,"model":"claude-3-5-sonnet","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}]}

data: {"id":"chatcmpl-xxx","object":"chat.completion.chunk","created":1699000000,"model":"claude-3-5-sonnet","choices":[{"index":0,"delta":{},"finish_reason":"stop"}]}

data: [DONE]
Note: This endpoint works with both Claude and Gemini models. The model is selected based on the prefix: claude-* routes to Claude, gemini-* routes to Gemini.

Claude Code Configuration

Add to ~/.claude/settings.json on the client machine:

{
  "env": {
    "CLAUDE_CODE_USE_VERTEX": "1",
    "ANTHROPIC_VERTEX_BASE_URL": "http://PROXY_IP:3030/v1",
    "ANTHROPIC_VERTEX_PROJECT_ID": "your-gcp-project-id",
    "ANTHROPIC_AUTH_TOKEN": "your-proxy-secret",
    "CLOUD_ML_REGION": "global",
    "CLAUDE_CODE_SKIP_VERTEX_AUTH": "1"
  },
  "model": "claude-opus-4-5@20251101"
}

Server Configuration

config/default.json

{
  "host": "0.0.0.0",
  "port": 3030,
  "users": [
    { "username": "user", "secret": "your-secret-token" }
  ],
  "vertex": {
    "location": "global",
    "project": "your-gcp-project-id",
    "useClientParams": false
  }
}
Field Description
users Array of authorized users with username and secret
vertex.project Default GCP project ID
vertex.location Default Vertex AI region
vertex.useClientParams If true, use project/location from URL instead of config

Environment Variables

Variable Description
NODE_ENV Set to development for detailed error messages
LOG_LEVEL Logging level: debug, info, warn, error
GOOGLE_APPLICATION_CREDENTIALS Path to service account JSON (default: config/vertex-ai.json)

Error Responses

Status Error Description
401 Authorization header required Missing Authorization header
401 Invalid token Token doesn't match any configured user secret
400 Unsupported model Model prefix not recognized (must start with claude or gemini)
500 Server configuration error Missing users or vertex configuration

All error responses include a requestId for debugging.

Quick Start

# 1. Authenticate with Google Cloud
gcloud auth application-default login

# 2. Configure config/default.json with your settings

# 3. Start the server
docker-compose up -d

# 4. View logs
docker-compose logs -f

# 5. Test the API
curl -X POST "http://localhost:3030/v1/projects/my-project/locations/global/publishers/google/models/gemini-2.0-flash" \
  -H "Authorization: Bearer your-secret-token" \
  -H "Content-Type: application/json" \
  -d '{"contents":[{"role":"user","parts":[{"text":"Hello!"}]}]}'
